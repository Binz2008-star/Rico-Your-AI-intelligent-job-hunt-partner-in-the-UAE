## What Was Done

### 1. Local-Only CSP Fix (apps/web/next.config.js)

**Change:** Added conditional `frame-src` for `https://sandbox-buy.paddle.com` when `NEXT_PUBLIC_PADDLE_SANDBOX=true`.

**Why:** Paddle Sandbox checkout iframe loads from `sandbox-buy.paddle.com`, not `checkout.paddle.com`. The original CSP blocked it.

**Scope:**
- Production CSP is unchanged — the sandbox domain is only added when the env var is set
- No `unsafe-inline` added
- No wildcard domains
- No `style-src` changes (the `sandbox-cdn.paddle.com` stylesheet violation is non-blocking and left as evidence for a future one-objective CSP PR)
- This change is local-only and uncommitted

- Backend: `uvicorn src.api.app:app` on `localhost:8000` with `.env.sandbox`
- Frontend: Next.js on `localhost:3001` with `NEXT_PUBLIC_PADDLE_SANDBOX=true`
- Database: Disposable Docker Postgres on `localhost:5432`
- Tunnel: `localtunnel` subdomain `loca-quiety-raccoon` for Paddle webhook delivery
